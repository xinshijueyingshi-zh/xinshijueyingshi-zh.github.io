SEQ.02

服务分镜 · 四个工种，一条链路

从一句模糊的想法，到能上线的成片，我们按模块接单，也可以整包交给团队推进。

BOARD A

短片与剧情片

品牌微电影、独立短片、剧情向内容。含剧本开发、选角建议、分镜预演与现场执行，适合需要“讲故事”而不是“堆产品”的项目。

  • 剧本诊断
  • 分镜预演 Animatic
  • 摄影 / 灯光 / 录音组
  • 2.39:1 宽画幅
索取分镜报价
BOARD B

广告片 TVC

15 / 30 / 60 秒三条版本同步交付，适配信息流、楼宇与电视台。脚本先过情绪测试，再进棚，减少返工。

  • 15″ 30″ 60″ 套剪
  • 棚拍 / 实景 / 航拍
  • 竖屏 9:16 版本
  • 字幕与多语言版
查看档期与预算区间
BOARD C

纪录片与口述影像

人物、非遗、企业历程、门店纪实。小机组跟拍，不干扰现场，声音单独采集，后期做轻量考据与字幕整理。

  • 小机组跟拍
  • 同期声采集
  • 采访灯光方案
  • 史实校订 / 字幕

SEQ.03

拍摄流程 · 五格走完，不玩失踪

每一步都有明确交付物和反馈窗口，不会出现“拍完再说”。时间以常规 30 秒广告片为基准，复杂项目另行排期。

01PRE-PROD

先聊清楚，再写脚本 沟通 2–3 轮

你给brief，我们回一页纸：目标人群、核心情绪、参考片单、忌讳点。确认后再进脚本，避免方向返工。

交付物：一页创意 brief + 脚本初稿　预计 3–5 天
02STORYBOARD

分镜与勘景，把预算花在刀刃上 可视化确认

手绘分镜加镜头表，标注焦段、灯光和转场；勘景同步出光线时间表，实景还是棚拍在这个阶段定死。

交付物：分镜稿 + 勘景报告 + 设备清单　预计 4–7 天
03PRODUCTION

现场只解决拍摄一件事 当日回看素材

导演、摄影、灯光、录音四条线各司其职，每天收工前和你过一遍素材，不把问题留到剪辑室。

交付物：粗剪前素材备份 + 场记单　拍摄 1–3 天
04POST

粗剪、声音、调色，逐轮收敛 两轮修改

先定剪辑节奏，再做声音设计和调色。每轮只收一个方向的修改意见，避免来回拉扯把片子磨平。

交付物：粗剪版 → 精剪版 → 调色母版　预计 7–12 天
05DELIVERY

多版本上线包，交付即能用 含版权清单

横版母版、竖屏剪裁版、方形社媒版一次给齐，附音乐授权与素材来源清单，投放端不用再追问。

交付物：4K 母版 + 3 个分发版本 + 授权清单

PRODUCTION NOTE · 072026 / 秋

新视觉影视成立于 2018 年，是个六人左右的小团队。我们接过的片子从三分钟的品牌短片，到跑了四个城市的纪录片，体量不一，但习惯没变过：先确定观众该有什么感觉，再决定画面怎么做。

不养“模板库”。同样的升格慢镜、同样的冷暖对比，用第二次我们自己会先腻。每条片子开工前会重新定一套色彩与节奏方案，成片里能看出来。

合作方式也简单：小项目按模块接，大项目整包推进，异地可以远程提案、现场再碰头。江浙沪当天可达，更远的地方按行程排。

没有脚本，只有一个模糊想法，能聊吗？

可以，而且这是最常见的开场。我们会先用 20 分钟问清三件事：给谁看、看完想让他们做什么、你手上有多少预算和几天。问完基本就能判断是走短片路线还是一条 15 秒信息流就够。

预算大概怎么分档？

轻量剪辑与调色按条算，品牌短片按分钟与工种算，TVC 按天搭组。页面不挂价目表是因为同样 30 秒，棚拍加航拍和一台机器拍一天能差五倍，报虚价没意思。给我们一个区间，会回一份拆得开的报价单。

只做后期、不发拍摄团队，接吗？

接。素材自己拍的、别人拍的都行，先发一段样片，我们看画质与灯光条件再报调色和剪辑的方案。S-Log3、C-Log3、BRAW 都常规处理，会把还原思路先给你确认再动手。

音乐和字体版权怎么处理？

成片交付时附一份授权清单：配乐来源、授权范围、字体商用许可、出镜人物肖像授权模板。投放端要查，直接把这份清单给他们。

修改几轮？超了怎么算？

精剪阶段含两轮结构性修改，调色阶段含一轮。超出部分按人天计，事前会先报价确认，不会干完再甩账单。小字幕、版本导出的改动不计入轮次。
